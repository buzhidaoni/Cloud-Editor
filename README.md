# Cloud-Editor

编程猫KITTEN作品云修改插件

基于 [S-LIGHTNING](https://github.com/S-LIGHTNING) 的 [源码云功能](https://github.com/S-LIGHTNING/Kitten-Cloud-Function)

## 用法
打开页面 *扩展程序* 

```
chrome://extensions/
```
```
edge://extensions/
```

随后，点开 *开发者模式* ，将插件拖入其中
